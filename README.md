نظام محاسبة متكامل مبني بأحدث تقنيات **Flutter** مع قاعدة بيانات **Firebase Firestore** السحابية. يغطي دورة العمل المحاسبية كاملة: الفواتير، العملاء، الموردين، المخازن، التقارير، والطباعة — مع لوحة تحكم ويب وإدارة صلاحيات متعددة الأدوار.

## 📋 About

A complete **accounting & inventory management system** built with Flutter and Firebase Firestore. It covers the full accounting cycle: invoicing, customers, suppliers, inventory, financial reports, and printing — with a web dashboard and multi-role permissions.

## ✨ Features | المميزات

- 🧾 Invoicing & printing (PDF / HTML / thermal) | الفواتير والطباعة الحرارية
- 📦 Inventory & stock management | إدارة المخازن والأصناف
- 📊 Financial reports & EOD sync | التقارير المالية وقفل اليومية
- 👥 Multi-user roles & audit log | صلاحيات متعددة وسجل تدقيق
- ☁️ Cloud sync via Firestore | مزامنة سحابية
- 🌐 Multi-platform (Android / Web / Desktop) | يعمل على أندرويد والويب والكمبيوتر

## 🛠 Tech Stack

`Flutter` · `Firebase Firestore` · `Riverpod` · `Google AdMob`

## ⬇️ Download & Run | التحميل والتشغيل

```bash
git clone https://github.com/Zuhairibrahim/accountingsystem.git
cd accountingsystem
flutter pub get
flutter run
```

> Requires Flutter SDK 3.x | يتطلب Flutter SDK
